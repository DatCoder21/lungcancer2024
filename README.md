This project combines two public CT-scan datasets — Chest CT-Scan Images (https://www.kaggle.com/datasets/mohamedhanyyy/chest-ctscan-images
) and IQ-OTHNCCD Lung Cancer Dataset (https://www.kaggle.com/datasets/adityamahimkar/iqothnccd-lung-cancer-dataset
) — and reorganizes them into five classes: Normal, Benign Tumor, Adenocarcinoma, Large Cell Carcinoma, and Squamous Cell Carcinoma. All images are preprocessed and augmented, and an additional High-Pass Filter (HPF) channel is generated to enhance edges and texture features. The final model input contains two channels (original + HPF). We train multiple pretrained architectures — VGG16, ResNet50, and InceptionV3 — after modifying their first convolution layer to accept 2-channel input. This combined dataset and multi-channel feature extraction approach aims to improve the accuracy and robustness of lung-disease classification from CT scans.
